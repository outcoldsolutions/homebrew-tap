# Outcold Solutions Homebrew tap

```bash
brew install --cask outcoldsolutions/tap/collectorformacos
```

Installs Collectord for [Monitoring macOS](https://www.outcoldsolutions.com/docs/monitoring-macos/), the signed and notarized package from https://packages.outcold.solutions. See [Installation](https://www.outcoldsolutions.com/docs/monitoring-macos/installation/) for the configuration it needs.
